# Mouse Latency Tools

Набор инструментов для Windows 10/11: замер задержки и стабильности мыши, нагрузки на процессор и FPS в CS2, плюс анализатор результатов с графиками и рекомендациями.

> 🤖 **Проект создан вместе с Claude** — ИИ-ассистентом компании Anthropic. Код скриптов и анализатора написан Claude по моим задачам и проверен на моём ПК (i5-10400F, RTX 3070 Ti, мышь 2000 Гц).

---

## 🛡️ Это не вирус и не чит

- **Весь код открыт.** Батники — обычный текст: ПКМ → «Изменить» (или откройте в Блокноте) и прочитайте всё, что они делают. Анализатор — один HTML-файл, его тоже можно открыть в любом редакторе.
- **Ничего не отправляется в интернет.** В скриптах нет ни одного сетевого запроса. Анализатор работает полностью в браузере, файлы никуда не загружаются. Для полной уверенности тесты можно проводить с выключенным интернетом (`network_toggle.bat`).
- **Ничего не меняется в системе.** Скрипты только *читают* данные: время отчётов мыши, загрузку процессора, настройки Windows. Исключения — `cs2_affinity.bat` (меняет привязку процесса CS2 к потокам, пока он запущен, — сбрасывается при перезапуске игры; ваш выбор потоков запоминается в `HKCU\Software\MouseLatencyTools`) и `network_toggle.bat` (выключает/включает сетевые адаптеры по вашей команде и запоминает их список в `%ProgramData%\MouseLatencyTools`).
- **В игру ничего не внедряется.** Скрипты не читают память игры, не нажимают клавиши и не двигают мышь.
- **Почему может ругаться антивирус или SmartScreen.** Скрипты запускают PowerShell, компилируют небольшой код C# (через стандартный `Add-Type`), следят за мышью и в режиме администратора включают трассировку ядра Windows (ETW) — так же работают LatencyMon, PresentMon и Windows Performance Analyzer. Эвристика антивируса может принять это за подозрительное поведение. Окно «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **Проверьте сами:** загрузите файлы на [VirusTotal](https://www.virustotal.com) и сравните контрольные суммы с [SHA256SUMS.txt](SHA256SUMS.txt).

## 📦 Что внутри

| Файл | Права администратора | Что делает |
|---|---|---|
| `mouse_analyzer.html` | — | Анализатор: открывается в браузере, принимает файлы замера, строит графики и даёт рекомендации. Внутри есть и быстрый замер прямо в браузере. |
| `mouse_latency.bat` | не нужны | Основной замер: частота опроса, интервалы и паузы, движение (быстрое / медленное / простой), характеристики мыши и USB, загрузка CPU по потокам и какие программы его нагружали. |
| `mouse_latency_admin.bat` | запросит сам | Всё то же + точный разбор, как в LatencyMon/WPA: какая программа работала на каждом потоке, время DPC/ISR каждого драйвера, а в игровом режиме — **FPS CS2** (средний, 1% и 0.1% low, время кадра, джиттер, фризы). |
| `cs2_affinity.bat` | не нужны | Не даёт CS2 занимать выбранные потоки CPU (например, тот, на который вы привязали прерывания мыши). Ждёт запуска игры и применяет настройку сам. |
| `network_toggle.bat` | запросит сам | 1 — выключить сетевые адаптеры, 2 — включить обратно, 3 — статус. Для тестов без интернета. |

## 🚀 Как пользоваться

1. **Скачайте** репозиторий: зелёная кнопка **Code → Download ZIP** и **распакуйте** в любую папку (из архива батники запускать нельзя).
2. **Запустите** `mouse_latency.bat` (или `mouse_latency_admin.bat` для точного разбора).
3. **Выберите** длительность и режим:
   - **обычный** — откроется окно теста на весь экран, двигайте мышь кругами;
   - **во время игры** — замер идёт в фоне, пока вы играете (см. предупреждение ниже).
4. **Дождитесь** окончания. На рабочем столе появятся файлы:
   - `mouse_ДАТА_1_info.txt` — характеристики мыши, системы, сводка движения
   - `mouse_ДАТА_2_latency.csv` — время каждого отчёта мыши
   - `mouse_ДАТА_3_movement.csv` — перемещение
   - `mouse_ДАТА_4_cpu.json` — процессор, потоки, программы, драйверы
   - `mouse_ДАТА_5_cs2_fps.csv` — кадры CS2 (только admin-версия в игровом режиме)
5. **Откройте** `mouse_analyzer.html` в браузере (Chrome, Edge, Firefox) и **перетащите** туда все файлы одного замера. Можно загрузить несколько замеров — появится сравнение.

В анализаторе есть кнопка **«Инструкция по оптимизации мыши и потока CPU»**: как узнать контроллер мыши через USB Device Tree Viewer, как привязать прерывания мыши к потоку в GoInterruptPolicy и как потом проверить результат.

## ⚠️ CS2: замер во время игры

- Добавьте в параметры запуска CS2 `-insecure` (Steam → ПКМ по игре → Свойства → Параметры запуска). VAC будет отключён, на защищённые серверы игра не пустит.
- Тестируйте **на ботах** или на своём локальном сервере.
- **Не запускайте** игровой режим в онлайн-матчах, Premier, FACEIT и ESEA. Скрипт ставит глобальный перехватчик мыши (как AutoHotkey) — в игру он не внедряется, но гарантий от ложного срабатывания античита нет.
- После тестов уберите `-insecure`.
- FPS записывается через события DirectX (DX11/DX12). С параметром `-vulkan` кадры не видны.
